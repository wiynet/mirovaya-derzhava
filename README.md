# Мировая держава — онлайн-стратегия на карте мира

Игрок выбирает страну, развивает экономику городов, нанимает армию, захватывает соседние города и строит ядерную программу.
На одном сервере (комнате) — до **50 игроков**. Если комната заполнена, игрока автоматически переводит в другую игру.

## Как выложить на Cloudflare (бесплатный тариф подходит)

1. Установите [Node.js](https://nodejs.org) версии 18 или новее.
2. Распакуйте архив, откройте терминал в папке проекта и выполните:
   ```bash
   npm install
   npx wrangler login      # откроется браузер — войдите в свой аккаунт Cloudflare
   npm run deploy
   ```
3. В конце wrangler напишет адрес вида `https://mirovaya-derzhava.<ваше-имя>.workers.dev` — это и есть игра.
   Имя можно поменять в `wrangler.jsonc` (поле `name`). Свой домен подключается в панели Cloudflare → Workers → Settings → Domains.

## Проверить у себя без Cloudflare

```bash
npm run local            # http://localhost:8787 — тот же сервер, но на вашем компьютере
```
Или `npx wrangler dev` — локальная копия настоящего Cloudflare.

## Как это устроено

| Файл | Что делает |
|---|---|
| `public/index.html` | Карта и весь интерфейс игры |
| `public/game.js` | Правила игры — один файл и для сервера, и для браузера |
| `public/data/*.json` | Границы стран, города (GeoNames), территории городов |
| `src/worker.js` | Cloudflare Worker: `Lobby` распределяет игроков по комнатам, `Room` — одна игра до 50 человек |
| `dev/server.mjs` | Локальный сервер для проверки |

- **Lobby** (Durable Object) знает, сколько людей в каждой комнате, и отправляет нового игрока в самую заполненную комнату, где ещё есть место. Если мест нет нигде — открывает новую.
- **Room** (Durable Object) хранит мир: владельцев городов, армии, деньги, ядерные программы. Состояние сохраняется после каждого хода, поэтому игра не теряется при перезапуске. Комната, в которой никто не играл 12 часов, начинается заново.
- WebSocket-соединения используют Hibernation API — пока никто ничего не делает, сервер «спит» и не тратит лимиты.
- Деньги начисляются непрерывно (доход в секунду), без таймеров на сервере.

## Правила (меняются в начале `public/game.js`)

- Старт: 1500 монет, все города вашей страны и небольшая армия в каждом.
- **Экономика** города: уровни 1–10, каждый уровень умножает доход города.
- **Армия**: 5 монет за солдата, вместимость города растёт с населением и экономикой.
- **Атака**: из своего города на любой чужой в радиусе 800 км. Если солдат больше, чем защитников, — город ваш. Столицы защищаются на 25% сильнее.
- **Переброска** войск между своими городами — до 1200 км.
- **Ядерная программа**: 5 этапов исследований, затем сборка боеголовок. Удар уничтожает армию города, половину населения и 3 уровня экономики; все игроки видят это в новостях.
